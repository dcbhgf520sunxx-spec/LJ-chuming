# IFC 性能优化验收记录（2026-11-12）

已完成此前体检确认的四项改动，并更新本地3120和服务器测试环境。测试服务器发布目录为 `20261112-160443-ifc-perf`，入口 `/bim/ifc-model-show`。源码通过 `codex/ifc-performance` 分支交付，提交信息以 Git 记录为准。

## 实现

1. 进度查询：按当前区域的目标构件一次聚合 MES、出入库、收货和安装数据，替换逐行重复子查询；结果字段、数量、重量和权限规则不变，无数据库结构变更。
2. 传输：Nginx gzip 压缩 JavaScript、JSON及 GLB。模型通过认证接口返回私有 ETag，200和304均按 Authorization、Accept-Encoding 区分；权限检查先于304。
3. 重复打开：最多保留两套已完成的原始模型资源，估算上限64MiB。每次打开重新验证访问权限，进度与详情仍读取当前数据；同一模型复用 ArrayBuffer及解码后的不可变几何。账号变化和退出登录清理复用数据，取消的请求不得覆盖后续选择。
4. 交互：构件树使用既有虚拟树，只渲染可见行，筛选输入防抖120ms。元件、构件和编号预建定位索引；点选仅更新变化颜色/轮廓。隐藏或聚焦压紧可见实例，空批次不提交绘制。相同编号的连续点选复用当前详情查询。

另修复发布流程：新通用构建保留部署环境已有的 BIM 浏览器配置与 CSP，避免覆盖原广联达入口的初始化配置。压缩200响应和304响应的强/弱 ETag按等价验证器比较，已加入回归测试。

## 性能实测

前值来自此前同一电脑的只读体检；本轮同时复测本地与服务器。电脑为 Chrome / Apple M5 Pro，1440×1000，模型为191件和1014件。打开耗时按选定模型至画面可操作统计，搜索下拉框输入等待另计。以下为样本结果，不作为任意设备、任意大小模型的固定承诺。

| 环节 | 优化前 | 本轮结果 |
|---|---:|---:|
| 较大模型首次打开 | 3.8–4.1秒 | 本地约0.95秒；服务器约1.0–1.3秒 |
| 较大模型重复打开 | 约4秒 | 本地约0.30秒；服务器0.33–0.46秒 |
| 较大模型，10Mbps/80ms模拟网络 | 约10.1秒 | 服务器约2.69秒 |
| 小模型，选项已准备好的首次资源请求 | 1.4–1.7秒 | 本地单次约0.32秒；包含首次项目筛选等待的样本约1.65秒 |
| 小模型重复打开 | 约1.4秒 | 本地约0.31秒 |
| 大模型几何+索引传输量 | 约10.5MiB | 实际约1.96MiB，减少约81% |
| 服务器大区域 SQL，同一只读快照 | 3048.64ms | 41.39ms，814行结果完全一致 |
| 点选引起的渲染状态更新 | 约12.6ms | 约1.2–4.6ms |
| 点击到业务详情 | 本地149–163ms | 本地热查询83–97ms，首个冷查询314ms；服务器185–243ms |
| 生产/发运/安装切换 | 约70–100ms | 本轮63/62/113ms，均恢复100%全景 |
| 聚焦测试单构件的绘制提交 | 648批次，约547万三角形 | 15批次，1668三角形 |
| Retina连续旋转 | 接近60帧 | 120个实际绘制帧，中位间隔16.7ms，仍接近60帧 |

大模型实际压缩体积：GLB 8,515,528→1,820,036字节，索引2,502,257→234,654字节。重复打开实测仅请求区域、进度和索引权限校验，索引返回304，不再请求几何文件。

构件树首次打开只生成16个可见/预渲染行。筛选输入的持续重复节点重建已消除；本轮输入阶段观察到一次65ms长任务，发生于首次树数据初始化，尚非全部交互零长任务。连续输入样本约695ms，其中包含40ms/字符的人工输入节奏及120ms防抖。

## 正确性和回归

- 服务器两个真实区域分别814、79行，与旧 SQL在同一只读事务中逐行完全一致。合成夹具覆盖同编号多条记录、不同单重、空值、无数据、软删除和任务类型过滤。
- 新缓存测试覆盖首次/重复、相同 ArrayBuffer、账号变化、清理、容量/LRU、错误响应、取消、过期异步完成，以及 gzip弱 ETag与304强 ETag的等价比较。独立复核复现了同账号旧请求晚失败会淘汰新缓存的竞争问题，已通过条目身份检查修正，并观察到回归测试由失败转为通过。
- Spring MVC探针验证项目/单体/区域/当前版本检查先于条件响应；普通、弱、列表验证器均覆盖。实际服务器304带私有缓存与Vary响应头；未登录携带 ETag仍返回业务未登录码40001，无模型 ETag。
- 已在浏览器模拟缓存访问被拒绝：旧模型不显示；进度请求失败：模型可操作并显示错误提示。快速切换单体后旧请求不回填，返回原单体可继续加载。
- 构件树展开、筛选、隐藏/显示、详情、编号定位、关闭后滚动1200→1200、三种状态及缩放复位通过。相同查看器逻辑的 CPU检查覆盖补充几何、实例压紧后的射线拾取、状态填色/轮廓及独立销毁。
- 高分屏使用实际 Metal / Apple M5 Pro GPU，DPR2时模型绘制像素比1.5。重复打开5次并显式回收后，样本 JS堆约135.5→133.6MiB，未观察到该短周期持续增长；不据此宣称长期运行已完全验证。
- 独立只读代码审查已完成，修复上述并发淘汰问题后未发现关键阻塞项。前端完整检查、生产构建、后端源构建、缓存/聚合探针、发布文件哈希及发布器4项测试通过。浏览器记录未见页面脚本异常。
- 本地和服务器健康状态均为UP，前端实际文件与构建资产一致。本地仅替换本次 IFC控制器，保留原有本地认证配置；服务器应用包与当前源构建一致。
- 服务器保留既有10.253.240.0/24出口网段、3GB后端堆、办公室访问范围和云 BIM模型映射。原广联达入口实际重新加载模型成功，无 viewToken错误。
