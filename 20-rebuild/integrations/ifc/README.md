# IFC 模型展示

入口为 BIM → IFC 模型展示，继承原模型展示菜单权限。接口按项目权限、单体和区域校验，模型文件位于私有目录，通过认证接口读取。浏览器使用本地 GLB 和构件索引，生产、发运和安装数量实时读取业务表。生产完成使用 MES 完工数量，发运使用仓库入库和出库数量，安装使用项目收货和安装数量。

后端配置项为 `ljaps.bim.ifc.directory`，默认目录 `/evidence/ifc-models`。发布目录须与后端的私有目录对应。

## 发布模型

几何由 IfcOpenShell 转为 GLB，经 gltfpack 的 `-kn -noq -c` 参数压缩。转换必须保留每个元素的 GlobalId，并检查缺失几何。带开孔板等转换异常应完成补充转换和几何核对后再发布。

转换环境使用 Python 3.12 和 `requirements.txt`，在本目录运行 `npm ci` 安装转换工具。缺失几何自动交由 web-ifc 补充解析，并与原 IFC 的世界坐标包围盒进行尺寸核对。补充转换失败时停止发布。也可通过 `--supplement` 提供经过核对的补充几何。

```bash
python3 20-rebuild/integrations/ifc/convert.py \
  --ifc /path/to/model.ifc --output /path/to/converted \
  --gltfpack /path/to/gltfpack
```

索引格式为 `{"parts":{"元素GlobalId":["所属构件GlobalId","构件编号"]},"assemblies":[{"id":"构件GlobalId","mark":"构件编号","position":"轴线位置","members":["元素GlobalId"]}]}`。可选的 `extraMeshes` 保存补充转换的 `id`、`positions`、`indices`。

```bash
python3 20-rebuild/integrations/ifc/publish.py \
  --root /path/to/private/ifc-models \
  --project 484 --monomer 679 --area 1412 \
  --geometry /path/to/model.glb --index /path/to/index.json
```

发布工具校验模型和索引，写入不可变版本目录，最后原子更新 `current`。浏览器携带版本号读取，换版后刷新。历史版本目录保留，可用原版本的文件重新发布以恢复。

构件编号只有汇总数量时，同编号多件的部分完工显示紫色和各状态数量。灰色表示未关联清单。模型清单与业务数量不一致时同样显示紫色，点选可查看数量。按状态筛选时，再点击同一状态可恢复。

本菜单覆盖三维浏览、项目树、构件树、编号搜索、元件定位、隐藏显示、状态筛选及生产、发运、安装进度。项目树按当前项目、单体和区域导航。构件树按编号、单件构件和元件展开，独立元件单列，节点按需加载。三类状态面板显示数量、重量及对应构件清单。方向立方体随相机转动，支持面、边、角定位、六向预设视图和恢复全景。模型转换由上述工具完成后发布。

工作区采用顶部筛选与搜索、左侧浮层、底部工具栏和右侧视角/缩放控件。项目树和构件树使用统一中性灰，选中构件或元件用玫红色高亮；三个进度模式使用对应的业务状态色。缩放始终以整体模型全景为 100%，范围为 10%—10000%；定位单件构件或子元件会留出周边空间，不重设缩放基准。切换到生产、发运或安装状态时恢复整体全景，避免继承单个零件的近景。关闭构件详情后保留构件树的展开、筛选和滚动位置。

点选模型或从构件树定位时显示业务构件详情，包括名称、编号、规格、材质、单毛重、长度、清单数量、单体/单元、批次、表面积、图纸及关联零件。业务详情按当前项目、单体、区域和编号精确读取；同编号对应多条清单时可选择记录，不任意合并规格或单重。表面积从原业务表 mm² 换算为 m²，缺失字段显示横线。构件树模式下选中构件显示玫红色；生产、发运和安装模式保留业务状态填色，用玫红轮廓标识选中项。详情内容首行右侧显示当前状态，与模型共用同一状态色表；从元件节点定位时仅标识该元件。图纸沿用已有预览，未上传时明确提示。

详情随查看模式变化：构件树提供图纸、关联零件和焊缝入口；生产模式显示当前生产状态；发运、安装显示当前状态、表面积和焊缝入口。详情不再展示状态数量分布和工序明细。项目树仅作范围导航。焊缝入口复用原有焊接工艺查看器，并传入当前项目、单体、区域和构件。无记录时显示空数据提示。

当前状态采用“彩色圆点 + 状态值”，位于详情属性表上方右侧。直接点击当前状态可打开深色状态图例，查看全部生产、发运、安装状态及特殊情况，标识当前查看模式和状态。状态旁不再额外展示“说明”文字。
